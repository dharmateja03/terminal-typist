# Terminal Typist 🚀

A MonkeyType-inspired typing speed test that runs entirely in your terminal!

## Features

- 🎯 Multiple test modes (30s, 60s, 2min, custom word count)
- 📊 Real-time WPM and accuracy tracking
- 🎨 Color-coded feedback (green=correct, red=incorrect)
- 📈 Detailed statistics after each test
- 🖥️ Works in any terminal
- 🚀 Lightweight and fast

## Installation

### From PyPI (Recommended)

```bash
pip install terminal-typist
```

### From Source

```bash
git clone https://github.com/dharmateja03/terminal-typist.git
cd terminal-typist
pip install -e .
```

## Usage

After installation, simply run:

```bash
typist
```

or

```bash
terminal-type
```

## Controls

- **Type** to start the test
- **Backspace** to correct mistakes
- **ESC** to quit current test
- **Any key** to continue from results

## Test Modes

1. **Quick Test** - 30 seconds
2. **Standard Test** - 60 seconds  
3. **Long Test** - 2 minutes
4. **Custom** - Choose your own word count (10-200 words)

## Requirements

- Python 3.6+
- Works on Windows, macOS, and Linux
- No additional dependencies (uses built-in `curses` library)
